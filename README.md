# El gráfico correcto para cada variable

Presentación web interactiva (6 láminas) para el Laboratorio 4 de *Técnicas de expresión oral y escrita* (Tecsup).

Tema: tipos de variables (nominal, ordinal, discreta, continua) y el gráfico adecuado para cada una.
Todos los datos de los gráficos son ilustrativos (ficticios).

## Uso
Abrir `index.html` en el navegador (funciona sin internet).

- `→` / clic: avanzar · `←`: volver
- `F`: pantalla completa · `H`: ocultar ayuda · `N`: guion de apoyo
- Acceso directo a una lámina y paso: `index.html#4.2` (lámina 4, paso 2)
- Se adapta a pantallas horizontales y verticales.
